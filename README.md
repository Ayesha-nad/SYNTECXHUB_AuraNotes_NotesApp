A modern, fluid, and beautifully animated React notes-taking web application built with **Tailwind CSS**, **Framer Motion**, and safe **`localStorage`** synchronization. Designed with inspiration from Notion, Linear, and Apple Notes.

---

## ✨ Features

- 🎨 **Curated Pastel Palette:** Choose from 7 curated aesthetic themes (`Butter`, `Sky`, `Blush`, `Mint`, `Lavender`, `Peach`, `Default`).
- ⚡ **Google Keep Expand Pattern:** Minimal initial note input that morphs into a full creation suite with tags, word count, and color swatches.
- 📌 **Pin High-Priority Notes:** Keep important notes locked to the top with spring-animated layout transitions.
- 🔍 **Live Search & Tag Filtering:** Instant search across titles, contents, and tags with sliding active pill filters.
- 💫 **Buttery Micro-Animations:** Staggered card entrances, 3D hover elevations, card exit fades, and celebration confetti.
- 💾 **Persistent `localStorage`:** Automatic syncing ensures notes survive refreshes and browser sessions.
- 🌓 **Dual Theme (Light & Dark Mode):** Hand-crafted color contrast for both day and night work.
- 📤 **Import & Export:** Export single notes (`.txt` / `.md`), backup all notes (`.json` / `.txt`), and restore backups.
- ⌨️ **Keyboard Shortcuts:**
  - `Ctrl + N` / `Cmd + N`: Focus note creator.
  - `Ctrl + Enter` / `Cmd + Enter`: Quick save note.
  - `Cmd + K` / `/`: Jump to search bar.
  - `Esc`: Cancel editing or dismiss modals.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Ayesha-nad/SYNTECXHUB_AuraNotes_NotesApp.git
cd SYNTECXHUB_AuraNotes_NotesApp
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### 4. Build for production
```bash
npm run build
```

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Confetti:** Canvas-Confetti
- **Storage:** Browser `localStorage`
